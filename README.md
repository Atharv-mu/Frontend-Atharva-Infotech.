Atharva Infotech — Next-Gen Computer Hardware & IT Services Platform
Atharva Infotech is a modern, high-performance e-commerce and IT service management web application built for hardware sales, custom PC builds, and technical service bookings. It features real-time price comparison against major platforms (Amazon, Flipkart), an interactive PC Builder with wattage calculation, a service booking wizard, dynamic multi-currency support, and an admin management portal.

🌟 Key Features
🛒 E-Commerce & Hardware Store
Best Price Guarantee Engine: Visual comparison badges showcasing Atharva Infotech’s lower prices compared to Amazon and Flipkart.

Smart Catalog & Filtering: Instant search, brand filters, category selection, price sliders, and Grid/List view toggles.

Product Quick View Modal: Technical spec sheets, availability status, warranty details, and key product highlights.

Shopping Cart & Wishlist: Slide-over drawer cart with promo code validation (TECH10 for 10% off), instant tax/discount calculations, and persistent wishlist tracking.

🖥️ Interactive Custom PC Builder
Dynamic Wattage Calculator: Real-time power supply (PSU) requirement estimation based on selected CPU, GPU, RAM, Motherboard, and Storage.

Live Component Selection: Automatically updates total build cost with single-click component swapping.

🛠️ IT Services & Booking Wizard
Comprehensive Service List: Computer Repair, Data Recovery, SSD Upgrades, Network Setup, Projector Installation, and Annual Maintenance Contracts (AMC).

Multi-Step Service Request: Select service type, service location (On-Site vs In-Store), preferred date/time slot, and generate an official repair ticket.

Instant WhatsApp Integration: Direct pre-filled inquiry buttons for quick consultation via mobile/desktop WhatsApp.

💳 Modern Checkout & Payment Simulation
UPI / QR Code Payment: Instant UPI payment modal with dynamically generated QR code, transaction ID input, and verification flow.

EMI / Installment Calculator: Real-time monthly breakdown across 3, 6, 9, and 12-month tenure options.

Printable Invoice Generator: Detailed downloadable/printable order confirmation receipt upon checkout completion.

⚙️ Admin Management Portal
Dashboard Metrics: Real-time overview of revenue, active service tickets, total orders, and inventory status.

Product Management: Quick stock adjustment, price editing, and product status toggling.

Service Request Queue: Live tracking and status updates for repair tickets.

🛠️ Technology Stack
Frontend Library: React 18 (Hooks, State Management, Context)

Styling: Tailwind CSS v3 (Utility-first styling, Glassmorphism, Custom animations)

Icons: Lucide Icons (lucide-react)

Build System: Single-file browser-ready bundle / Next.js compatible component structure

Font: Inter / Modern System UI Stack
