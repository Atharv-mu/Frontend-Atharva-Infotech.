# Atharva Infotech – Next-Gen Computer Hardware & IT Services Platform

**🌐 Live Website:** https://atharva-infotech.onrender.com/

Atharva Infotech is a modern, feature-rich e-commerce and IT service management platform designed to simplify computer hardware shopping, custom PC building, and technical service bookings. The platform brings hardware sales and IT solutions together in one place, offering customers a seamless, intuitive, and efficient digital experience.

From exploring hardware products and comparing prices to configuring custom PCs and booking technical services, Atharva Infotech provides an integrated solution for both individual customers and businesses.

## 🌟 Key Features

### 🛒 1. E-Commerce & Hardware Store
- **Competitive Price Comparison:** Highlights Atharva Infotech's pricing against major marketplaces like Amazon and Flipkart, helping customers identify better-value deals.
- **Smart Product Catalog:** Includes instant search, brand and category filters, price-range controls, and flexible Grid/List viewing options.
- **Product Quick View:** Displays detailed technical specifications, product availability, warranty information, and key highlights.
- **Shopping Cart & Wishlist:** Offers a convenient slide-out cart, persistent wishlist, and promo code support.
- **Discount & Tax Calculation:** Automatically calculates discounts, taxes, and final payable amounts. Includes the TECH10 promo code for 10% off.

### 🖥️ 2. Interactive Custom PC Builder
- **Real-Time Component Selection:** Allows users to configure custom PCs by selecting and swapping CPUs, GPUs, RAM, motherboards, and storage.
- **Dynamic Wattage Calculator:** Estimates overall system power requirements based on the selected components.
- **Live Price Calculation:** Automatically updates the total build cost whenever components are added or changed.
- **Simplified PC Configuration:** Helps customers plan hardware builds according to their performance requirements and budget.

### 🛠️ 3. IT Services & Online Booking
- **Comprehensive Service Portfolio:** Covers computer repairs, data recovery, SSD upgrades, network configuration, projector installation, and Annual Maintenance Contracts (AMC).
- **Step-by-Step Booking Process:** Guides customers through service selection, location preferences, appointment dates, and available time slots.
- **Flexible Service Options:** Supports both on-site assistance and in-store service requests.
- **Repair Ticket Generation:** Generates service request details for easier tracking and management.
- **WhatsApp Integration:** Provides direct inquiry options with pre-filled messages for faster customer communication.

### 💳 4. Checkout & Payment Experience
- **UPI Payment Interface:** Includes a QR-based payment flow with transaction ID submission and a verification interface.
- **EMI Calculator:** Calculates estimated monthly installments for 3, 6, 9, and 12-month payment plans.
- **Automated Order Summary:** Displays applicable discounts, taxes, and final payment details.
- **Printable Invoice:** Generates a detailed order confirmation and printable invoice for customer records.

### ⚙️ 5. Admin Management Portal
- **Dashboard & Analytics:** Provides an overview of revenue, orders, active service requests, and inventory status.
- **Product Management:** Enables administrators to update product prices, adjust stock quantities, and manage product availability.
- **Service Request Management:** Offers a centralized interface for reviewing repair tickets and updating service statuses.
- **Operational Overview:** Helps streamline day-to-day store and service management activities.

## 🧰 Technology Stack

- **Frontend:** React 18 (Hooks, Context API, State Management)
- **Styling:** Tailwind CSS v3
- **Icons:** Lucide React
- **Typography:** Inter / Modern System UI
- **Build & Architecture:** Browser-ready single-file bundle with a Next.js-compatible component structure
- **UI & UX:** Responsive layouts, glassmorphism, modern animations, and interactive components

## 🎯 Project Objective

The primary goal of Atharva Infotech is to create a unified digital platform that makes computer hardware purchasing, custom PC configuration, and IT service management more accessible and convenient.

By combining e-commerce functionality, intelligent PC building tools, service booking workflows, and administrative management in one application, the platform demonstrates how modern web technologies can improve the overall customer experience while simplifying business operations.
